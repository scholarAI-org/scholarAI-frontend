# Country options

Source: https://github.com/mledoze/countries (countries.json, retrieved 2026-09-05).
The original ODbL license in countries-LICENSE.txt applies to this derived dataset.

The profile fetches this snapshot from the same origin because REST Countries
v3.1 was retired and v5 requires an API key.

To refresh, map source entries to value (cca2), label (nonempty Arabic common
translation, falling back to common name), and nationalityLabel (nonempty
English male demonym, female demonym, then common name). Sort labels using Arabic
collation. Preserve the two-letter codes used by saved profiles.
